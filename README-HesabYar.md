# حساب‌یار — نسخه اولیه اندروید
برنامه آفلاین ثبت دریافتی، پرداختی و بدهی با تاریخ شمسی.

## ساخت
با هر push روی main، GitHub Actions تلاش می‌کند APK آزمایشی را بسازد. پس از اجرای موفق، از Actions > Build HesabYar APK > Artifacts، فایل hesab-yar-apk را دانلود کنید.

## قابلیت‌ها
- ثبت دریافت، پرداخت و بدهی با شرح و تاریخ شمسی خودکار
- گزارش ماه شمسی جاری و محاسبه مانده
- تسویه بدهی با انتقال به پرداختی
- ذخیره محلی روی گوشی
- بدون بخش «آخرین تراکنش‌ها» در داشبورد

این APK تا پایان موفق GitHub Actions ساخته‌شده محسوب نمی‌شود.
